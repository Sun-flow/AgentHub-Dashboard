# Deliverable 2: Google Stitch visual proposal

Design guidance only. Not the final deliverable, and not code to copy.

## Steps

- [ ] `SPECS.md` (first draft) is committed (P3).
- [ ] Prompt Google Stitch with the contents of `SPECS.md`. (Stitch is a Google
      web tool; mae runs it, or an agent with browser access does.)
- [ ] Save the result where future agents can see it: screenshots under
      `context/design/` and a short note on what to keep and what to change.
- [ ] Compare the proposal against [../definition-of-done.md](../definition-of-done.md)
      and list every place it diverges (missing sections, wrong components,
      missing interactions, extra features).
- [ ] Decide the visual direction to adopt (colors, typography, spacing, icon
      style) and, if it changes the spec, update `SPECS.md` in a new commit.

## Completion checklist

- [ ] P4 proposal generated from `SPECS.md`
- [ ] Divergences from the brief listed
- [ ] Visual direction recorded in `SPECS.md` or `context/design/`
- [ ] Nothing from Stitch is adopted that conflicts with the brief (P5)

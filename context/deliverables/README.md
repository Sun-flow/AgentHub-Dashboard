# Deliverables

The project produces three things, in this order. Each has a completion
checklist. A deliverable is complete only when every box is checked.

| # | Deliverable | Checklist | Depends on |
| --- | --- | --- | --- |
| 1 | `SPECS.md` at the repo root, in its own commit | [1-specs.md](1-specs.md) | Open questions answered or defaulted ([../open-questions.md](../open-questions.md)) |
| 2 | Google Stitch visual proposal (design guidance only) | [2-stitch-proposal.md](2-stitch-proposal.md) | 1 committed |
| 3 | HTML prototype | [3-prototype.md](3-prototype.md) | 1 committed, 2 reviewed |
| — | Final review before handing off | [4-final-review.md](4-final-review.md) | 3 complete |

IDs like `S3` or `D2.4` refer to [../definition-of-done.md](../definition-of-done.md).
